# Zyrox Media — Digital Marketing Agency Website

Official website for **Zyrox Media**, an elite digital marketing and brand acceleration agency specializing in social media management, reel & content production, high-conversion web development, SEO, and Meta ads.

---

## 🚀 Features

- **Dynamic Canvas Preloader**: Particle swirl vortex with marketing buzzwords and smooth Iris reveal animation.
- **Hero Section**: High-impact typography, dual CTAs, interactive floating stat cards, and glowing visual depth.
- **What You Get Every Month**: High-density deliverables grid with hover-reactive cards and animated badges.
- **How We Work**: 6-step battle-tested workflow timeline with scroll progress tracker.
- **Why Choose Zyrox**: Interactive comparison matrix (Zyrox Media vs. Typical Freelancers vs. Traditional Big Agencies).
- **Interactive Service Modules**: 8 core digital marketing service cards with spotlight cursor effects.
- **Founder & Team Showcase**: 
  - Founder introduction for **Chandan Rai** with rotating metric rings.
  - Interactive **Cinematic Portfolio Intro Modal** powered by real-time WebAudio synthesis, animated typography, and sound effects.
  - 3D tilt team member cards with social handles.
- **Featured Projects**: Filterable case histories with cursor-following previews and real business metrics.
- **Client Testimonials**: Verified testimonials with performance badges and client quotes.
- **FAQ Accordion & Contact Form**: Accessible FAQ accordion and conversion-optimized lead capture form.
- **Dynamic Footer**: Marquee banner, quick links, and social links.

---

## 🛠️ Tech Stack

- **HTML5 & Modern CSS3** (CSS custom properties, clamp typography, backdrop blur, CSS grid & flexbox)
- **Vanilla JavaScript (ES6+)** with zero external runtime dependencies
- **WebAudio API** for synthesized UI sound effects
- **HTML5 Canvas 2D** for high-performance particle animation
- **Node.js Local Server** (`server.js`) for rapid local preview

---

## 💻 Local Development

Run the local server using Node.js:

```bash
node server.js
```

Then open your browser and navigate to:

```
http://localhost:3000/
```
